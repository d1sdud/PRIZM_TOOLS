# PRIZM AE 도구

애프터이펙트 패널의 **본체**를 두는 곳이다. 여기 있는 파일은 각자 맥에 깔린
즐겨찾기(`ScriptUI Panels/check IN EVENT.jsx`)가 패널을 열 때마다 받아 간다.
그래서 **여기에 올리면 팀 전체가 다음에 패널을 열 때 최신본을 쓴다.**

| 파일 | 도구 |
|---|---|
| `checkin-event-tool.jsx` | check IN EVENT — 체크인 라이브 이벤트 영상 대판 조립 |

## 왜 공개 저장소인가

애프터이펙트는 `https` 를 직접 못 읽어서 즐겨찾기가 `curl` 로 받아 온다. 비공개
저장소면 그 `curl` 에 GitHub 토큰을 넣어야 하는데, 그 토큰이 팀원 맥의 캐시 파일에
평문으로 남는다. 공개로 두면 토큰이 아예 필요 없다.

**열쇠는 여기 없다.** 피그마·일레븐랩스 키는 각자 패널에 직접 넣어 자기 맥에만
저장된다. 이 저장소에 올라가는 것은 도구 코드뿐이다.

## 고치는 곳은 여기가 아니다

원본과 설명은 [d1sdud/RXC](https://github.com/d1sdud/RXC) 의 `event-video/` 에 있다.
이 저장소는 배포용 사본이라, **여기서 직접 고치면 다음 배포 때 덮어써진다.**
